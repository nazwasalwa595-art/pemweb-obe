# AbsensiQR - Landing Page System

Proyek ini merupakan implementasi halaman landing page untuk sistem absensi berbasis QR Code (**AbsensiQR**). Proyek dibuat menggunakan struktur HTML5 murni yang mematuhi standar aksesibilitas web dan hirarki dokumen yang baik.

---

## Deskripsi Singkat Halaman

Halaman utama (`index.html`) dirancang untuk memfasilitasi kebutuhan informasi absensi bagi guru, dosen, siswa, dan mahasiswa. Halaman ini mencakup:
* **Header & Navigasi**: Akses cepat navigasi utama dan fitur *skip to main content*.
* **Hero Section**: Informasi utama layanan beserta tombol tindakan (Login/Daftar) dan ilustrasi visual.
* **Fitur Utama**: Tiga poin keunggulan layanan (Berbasis QR, Aman, dan Mudah Digunakan).
* **Form Kontak**: Form interaktif *Hubungi Kami* dengan elemen input yang teraksesibel.
* **Footer**: Informasi hak cipta situs.
